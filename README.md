## key features using bullet points.

Dynamic Service Listing & Search: Browse, find, and search real service listings retrieved from MongoDB

Secure Authentication: Firebase authentication system with email/password and Google login.

Service Provider CRUD: Providers can add, edit, and delete their own services (Get, Post ,Update, Delete).

Responsive, Animated UI: Fully responsive design for mobile/tablet/desktop with animations using framer-motion.

Toasts & Sweet Alerts: toast notifications or SweetAlert2.
