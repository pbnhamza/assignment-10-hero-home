# 🏠 Hero Home

Hero Home is a modern service marketplace platform where users can explore real service listings and providers can manage their own services. With a smooth UI, secure authentication, and full CRUD functionality, Hero Home delivers a fast and reliable user experience.

---

## 🌐 Live Site URL

🔗 **Live Demo:** https://heartfelt-figolla-eec98b.netlify.app/


---

## 📚 Overview

Hero Home is a full-stack web application designed to connect users with high-quality services.  
The platform includes a dynamic service listing system, robust authentication, provider dashboards, and responsive UI powered by animations.  
It ensures a seamless and engaging experience across desktop and mobile devices.

---

## ✨ Key Features

### 🔍 **Dynamic Service Listing & Search**
- Browse real services pulled from MongoDB  
- Fast search and filtering  

### 🔐 **Secure Authentication**
- Firebase Email/Password login  
- Google Sign-In integration  

### 🧰 **Provider Dashboard with CRUD**
- Add new services  
- Edit existing services  
- Delete services  
- Manage everything from a protected dashboard  

### 📱 **Responsive, Animated UI**
- Fully responsive on mobile, tablet, and desktop  
- Framer Motion animations for smooth interactions  

### 🔔 **Toasts & Sweet Alerts**
- Beautiful notifications using **react-hot-toast**  
- Alerts and confirmations using **SweetAlert2**
