## 📝 Project Description

Hero Home is a full-stack web application designed to connect users with high-quality services in a seamless and efficient way. It features a dynamic service listing interface, strong authentication system, and powerful CRUD operations for service providers. With a responsive design and smooth animations, users can enjoy a fast, intuitive, and interactive experience across all devices.

---

## ✨ Key Features

### **Dynamic Service Listing & Search**

Browse through real services retrieved from MongoDB, with fast search functionality to find exactly what you need.

### **Secure Authentication**

Firebase-powered login system with Email/Password and Google Sign-In for smooth and safe user access.

### **Service Provider CRUD**

Providers can **Create**, **Read**, **Update**, and **Delete** their own services—fully managed through a protected dashboard.

### **Responsive, Animated UI**

Designed for all devices—mobile, tablet, and desktop—enhanced with beautiful animations using **Framer Motion**.

### **Toasts & Sweet Alerts**

User-friendly interactions powered by **react-hot-toast** and **SweetAlert2** for confirmations, warnings, and success messages.
